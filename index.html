    How to run the test

    1. On your iPhone, open this page in Chrome. Tap Share, then Add to Home Screen. If Chrome does not offer it, tell me. We will try Safari.
    2. Open the app from its home screen icon. The top badge should read "Running as installed app".
    3. Save two entries. Check the status list: service worker active, offline copy ready.
    4. Turn on airplane mode. Close the app fully, then open it again. It should load and show both entries.
    5. Turn airplane mode off. Leave the app alone for 7 days or more, then open it again. Check First opened is unchanged and the entries are still there.

    Report which step failed and what the status list says.
