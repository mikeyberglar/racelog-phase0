    How to run the test

    1. Open this page once in Chrome, then Share, Add to Home Screen. From then on, use only the new home screen icon.
    2. Create an account, then save one entry with signal. It should turn Confirmed on server within a few seconds.
    3. Turn on airplane mode. Save three entries. They should read On device only.
    4. Close the app fully, then open it again, still offline. All four entries should be listed.
    5. Turn airplane mode off. Wait up to 20 seconds or tap Sync now. All four should read Confirmed with no repeats.
    6. Tick Simulate a lost reply, save one entry, then tap Sync now twice. The entry should end Confirmed once, with Possible repeats at 0.
